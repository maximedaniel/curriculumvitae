# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Quarto website (`project: type: website`) serving Maxime Daniel's academic CV at www.maximedaniel.me, plus a set of standalone teaching/research pages (`research.qmd`, `design-methods.qmd`, `user-scenario.qmd`, `paper-writing.qmd`, `statistics.qmd`, etc.). There are no tests or linters.

## Commands

- `./run.sh` — regenerate the printable variants (see below) and run `quarto preview --no-browser`.
- `quarto render` — build the site into `_site/` (gitignored).
- `./deploy.sh` — regenerate printable variants, render, tar `_site` + `Dockerfile`, scp to the server, and rebuild/run the `cv` Docker container (Node `http-server` on port 5000, behind nginx). After a server reboot: check the container is running and `systemctl restart nginx`.

The scripts are bash (use Git Bash/WSL on Windows; they rely on `sed -i`).

## CV architecture: data in YAML, HTML generated by Lua filters

- `index.qmd` is almost entirely YAML front matter (~3,500 lines) holding all CV data: `profil`, `experiences`, `educations`, `theses`, `projects`, `publications`, `reviews`, `supervisions`, `animations`, `coordinations`, `lectures`, `missions`. Text fields are bilingual objects (`en:` / `fr:`). The markdown body is only a layout skeleton of empty fenced divs such as `::: {.publications}\n:::`.
- `_quarto.yml` registers `filters/main.lua` globally. `main.lua` walks the document, and each empty div whose class matches a section name is replaced by a `RawBlock("html", ...)` produced by `filters/<section>.lua`'s `render(metadata, debug)`. Each module reads its own section from the metadata, picks the language via `metadata.lang`, and builds Bootstrap HTML strings by hand.
- To add a CV entry, edit the YAML in `index.qmd`. To add a new section type, you need to: create `filters/<name>.lua`, add it to `package.path` and the `require`s in `main.lua`, add it to both `render_div_for_class` and `classes_to_check`, and add the div to the body of `index.qmd`.
- Metadata flags change rendering: `printable: true` makes filters emit plain links instead of buttons and expand collapsed content; `lang`/`en`/`fr` select the language (headings use `.content-visible when-meta="en|fr"`).

## Printable variants are generated, not hand-edited

`printable_en.qmd` and `printable_fr.qmd` are overwritten by `run.sh`/`deploy.sh` as copies of `index.qmd` with `printable: true` (and `lang: fr`, `fr: true` for the French one). Always edit `index.qmd`, never the printable files.

To produce the PDF CV (per README): open the printable page in Firefox, print to PDF; to remove headers/footers, blank the `print.print_header*`/`print.print_footer*` keys in `about:config`.

## Other files

- `js/` — client-side scripts injected on every page via `_quarto.yml` (jQuery, collapse buttons, YouTube/video embedding, the printable toggle that hides buttons and expands collapses).
- `bibliography.bib` + `sigchi-ext.csl` — citations for the content pages.
- `pdf/`, `img/`, `gif/` — assets referenced from the YAML (`pdf:`, `thumbnail:` fields).
- `to_integrate/` — React `.tsx` components not wired into the build.
